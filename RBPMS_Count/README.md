# RBPMS 阳性 RGC 网页审核

## 在 Windows 启动

1. 在项目目录运行 `install_web.cmd` 安装依赖。本项目已使用 Python 3.12 验证。现有 `.venv` 若已具备依赖，可直接启动。
2. 运行 `start_web.cmd`，保持命令窗口开启。
3. 启动脚本会选择空闲端口并在 Windows 默认浏览器中打开审核页。也可以把启动窗口显示的地址复制到 Edge 或 Chrome。
4. 可用 `start_web.cmd --project "E:\研究生\统计\RBPMS_Count\我的实验"` 指定项目目录，或用 `--port 8766` 更换端口。默认项目目录为 `review_project`。

服务只监听本机回环地址。原图以副本形式存入选定项目目录。关闭启动窗口即可停止服务。

## 浏览器分享版

分享版由 `share_web/build.py` 生成，并复用同一套 Python 分割和审核逻辑。它将运行组件、图像处理和项目存储放在访问者的浏览器内。现有 Windows 项目和浏览器项目分别保存。浏览器项目可在同一浏览器和网址下继续审核，清除网站数据会清空该浏览器里的项目。首次打开需要加载分割运行组件。

## 导入和审核

- 导入一张 8-bit PNG，选择绿色、红色或自动判断通道。只选原图时自动运行 V3 Watershed。自动判断比较红、绿通道，红绿信号接近时会要求手选。已有 V3 结果可同时选择对应的 `*_v3_labels16.png` 与 `*_v3_cells.csv`。请核对三份文件来自同一原图及同一次分割，程序会核对图像尺寸和候选 ID。
- 青色为高可信候选，初始计入。黄色为弱阳性待审，紫红色为疑似伪影，两者初始待审。计入候选显示中心点，人工新增显示白圈。
- 智能切换模式下，点击候选切换计入状态，点击空白新增细胞，点击已有白圈移除。添加 / 确认模式可确认已经计入的高可信候选，推进审核进度。排除模式可取消计入或删除白圈。
- 使用滚轮缩放，拖动平移，工具栏可恢复适合窗口或切到 100%。Ctrl+Z 和 Ctrl+Y 可撤销和重做。
- 页首显示「已保存」后，可刷新或关闭网页。用同一项目目录重新启动即可继续。原图按文件内容 SHA-256 去重，重复导入会打开已有记录。若要比较同一原图的另一组 V3 标签，请使用另一个项目目录。
- 单张导入默认自动判断红绿通道。如果原图已因选错通道而没有任何分割候选，且当前没有人工计入点，可选正确通道重新导入。项目会沿用同一图像 ID，保留旧分割文件和审核日志，并从新分割开始新的撤销历史。
- 审核结束后点击右侧「完成审核」。当前图像与项目汇总计数 CSV 都按「文件夹名、自动计数、人工审核后计数」三列导出，带 UTF-8 BOM。批量图像使用直接所在的文件夹名，单张上传使用图片文件名。第三列在确认前留空，确认后记录当前计入数。之后如修改、撤销或重做审核操作，需再次点击「完成审核」。PNG 为原始像素尺寸的标注图。

## 批量计数

1. 打开左侧「批量计数」，选择根文件夹。清单会递归列出文件名主体以 `_c1` 结尾的 PNG，跳过 `_c2` 和 `_c1+2`。可修改后缀并重新生成清单。
2. 同一子目录出现多个匹配图像时，先预览并勾选要处理的图像。可为整张清单设置通道，也可逐图修改。
3. 点「计数所选图像」开始。暂停会等待当前图像写入后停止队列，再次开始会继续处理尚未完成的勾选项。关闭网页后，可重新选择同一文件夹，已有图像按内容去重并保留审核记录。
4. 下载「项目汇总 CSV」查看每张图像的三列计数。项目内部保留相对路径和通道。同内容文件采用首次导入的路径。比较同一原图的不同通道时请使用独立项目目录。
5. 处理完后，可在「管理项目图像」中多选并移除。批量窗口里的「管理本批已导入图像」会预选本批新增项。移除的图像会从项目列表和汇总 CSV 隐藏，可在「已移除」中恢复审核记录。

## 示例项目结构

```text
review_project/
  review.sqlite3
  images/
    <原图 SHA-256>/
      source.png
      source_v3_labels16.png
      source_v3_cells.csv
```

SQLite 的 `images` 表保存图像索引、审核快照、撤销位置和修订号。 `audit` 表保留实际修改与撤销、重做事件。备份时关闭服务并复制整个项目目录。可用现有 `images` 与 `results_v3` 文件夹中的同名样图和结果试用。

## 测试

在项目目录运行 `.venv\Scripts\python.exe -m unittest -v test_web_review`。有 Node.js 22+ 和 Edge 时，运行 `node test_web_browser.mjs` 可在临时项目中测试浏览器的导入、缩放、平移、审核和恢复。如使用其他 Chromium 浏览器，可通过 `RBPMS_BROWSER` 指定可执行文件路径。

## 实现范围与后续计划

网页采用原生 HTML、JavaScript Canvas、Python 本地 HTTP 服务和 SQLite。绿色分割沿用 V3 默认参数，红色分割采用 V2 的红色分割下限和最小种子间距，候选分类仍使用 V3 规则。审核沿用桌面工具的标签像素命中及近邻规则。

1. 扩展 TIFF 导入、样本元数据和跨会话批次清单恢复。
2. 算法阶段加入血管绘制与弱候选重评、参数比较和可选 Cellpose。对有逐细胞标注的独立样本计算 Precision、Recall 和 F1，对匹配文件名的参考计数计算总数误差。
3. 科研工作流阶段加入完整项目管理、参数版本、审核日志导出和 Excel 等批量导出。

当前计数是候选和人工审核的结果。现有样图回归测试用于检查与 V3 的一致性，识别准确性需要独立的逐细胞标注验证。
